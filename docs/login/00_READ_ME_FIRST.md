## 💡 Tips & Tricks

### For Testing
- Click demo buttons for quick testing
- Use browser DevTools (F12) to inspect localStorage
- Check Console for helpful error messages
- Test on different screen sizes

### For Customization
- Edit VALID_USERS in AuthContext.tsx to add/remove users
- Change password in AuthContext.tsx
- Modify colors in Login.css
- Adjust animations (timing, effects)

### For Development
- Use `useAuth()` hook in any component
- Check `isAuthenticated` before rendering
- Access `user.name` and `user.email` for display
- Call `logout()` to clear session

### For Production
- Replace with Azure AD authentication
- Move VALID_USERS to backend database
- Use actual password hashing
- Implement token-based auth
- Add refresh token mechanism

## 🐛 Troubleshooting

### Common Issues

**Q: Login page not showing**
A: Check App.tsx has `if (!isAuthenticated) return <Login />`

**Q: Can't login with email**
A: Email must be in VALID_USERS list (exact match, case-insensitive)

**Q: Styles not loading**
A: Verify CSS files in styles/ folder and index.css has sidebar content

**Q: Getting TypeScript errors**
A: Check file paths in imports use correct folder structure

**Q: Still shows login after login**
A: Clear browser localStorage and cache, then try again

See **QUICK_SETUP.md** for full troubleshooting section.
