## ✨ Animation Examples

### 1. Logo Pulsing Glow (3 seconds)
```
Animation Duration: 3 seconds (repeating)

0%:   Box Shadow: 0 20px 25px -5px rgba(59,130,246,0.4)
      (Medium blue glow)

50%:  Box Shadow: 0 25px 50px -5px rgba(139,92,246,0.6)
      (Intense purple glow - peak)

100%: Box Shadow: 0 20px 25px -5px rgba(59,130,246,0.4)
      (Back to medium blue)

Result: Smooth breathing/pulsing effect on the "E" logo circle
```

### 2. Floating Blobs (8 seconds each, staggered)
```
Animation Duration: 8 seconds per blob

Blob 1 (top-left, blue):
  0%:   translate(0px, 0px)
  33%:  translate(30px, -50px) ← Move right and up
  66%:  translate(-20px, 20px)  ← Move left and down
  100%: translate(0px, 0px)     ← Back to start

Blob 2 (bottom-right, purple):
  Delay: 2 seconds (starts after blob 1)
  Same movement pattern

Blob 3 (right-center, cyan):
  Delay: 4 seconds
  Same movement pattern

Result: Three blobs gracefully floating around continuously
```

### 3. Button Hover Effect
```
Normal State:
  ✓ Blue-to-purple gradient
  ✓ Shadow: 0 10px 25px -5px rgba(59,130,246,0.3)

Hover State (instant):
  ✓ Same gradient (unchanged)
  ✓ Transform: translateY(-2px) ← Lifts up slightly
  ✓ Shadow: 0 15px 35px -5px rgba(59,130,246,0.4) ← Glow increases
  ✓ Shine effect: Gradient slides left-to-right across button

Result: Button appears to float up with increased glow
```

### 4. Error Banner Shake
```
Animation Duration: 0.5 seconds (one-time)

0%:   transform: translateX(0)
25%:  transform: translateX(-5px) ← Shake left
75%:  transform: translateX(5px)  ← Shake right
100%: transform: translateX(0)    ← Stop

Result: Quick left-right shake motion
Used when: Invalid login attempt
```

### 5. Floating Particles (20 seconds continuous)
```
Animation Duration: 20 seconds per particle

12 particles total, staggered by 0.1 seconds each:

0%:    translate(0, 0), opacity: 0     ← Start invisible
10%:   opacity: 1                      ← Fade in
90%:   opacity: 1                      ← Stay visible
100%:  translate(randomX, -randomY)    ← Float upward
       opacity: 0                       ← Fade out

Each particle has unique random X,Y movement vectors
Result: Continuous gentle upward floating and fading
```

### 6. Card Slide-In (on page load)
```
Animation Duration: 0.6 seconds (one-time)

From:
  ✓ transform: translateY(30px) ← Starts 30px below
  ✓ opacity: 0                  ← Invisible

To:
  ✓ transform: translateY(0)    ← Moves to final position
  ✓ opacity: 1                  ← Fully visible

Easing: ease-out (starts fast, ends slow)

Result: Card smoothly slides up into view
Used when: Page loads
```

### Password Input
```
Normal:     Same as email, eye icon visible
Focus:      Same as email, eye icon remains
Visible:    Type="text", eye icon shown
Hidden:     Type="password", eye icon shown
Toggle:     No page reload, instant switch
```
